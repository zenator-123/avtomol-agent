# Ежедневно обновяване на автомобилите

Автоматизацията управлява само продукти с етикет `vehicle-sync` и входящ номер в полето `custom.incoming_number`. Авточастите не се засягат.

## Поведение

- наличен входящ номер, който липсва в Shopify: създава продукт и Facebook публикация;
- входящ номер, който вече липсва от наличностите: изтрива Facebook публикацията и след това Shopify продукта;
- по подразбиране работи в пробен режим и само показва плана;
- спира при празен/твърде малък каталог или необичайно много изтривания.

## GitHub Secrets

- `SHOPIFY_SHOP_DOMAIN` — реалният `*.myshopify.com` домейн;
- `SHOPIFY_ACCESS_TOKEN` — токен с `read_products` и `write_products`;
- `FACEBOOK_PAGE_ID`;
- `FACEBOOK_PAGE_ACCESS_TOKEN` — достъп до управляваната страница;
- `INVENTORY_FEED_URL` — JSON адрес с актуалните автомобили;
- `INVENTORY_FEED_TOKEN` — само ако източникът го изисква.

За реална ежедневна работа се създава repository variable `SYNC_DRY_RUN=false`, след успешен пробен отчет.
